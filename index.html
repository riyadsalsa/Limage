🧙 Setup wizard (first run)

The first time you open the app, a wizard runs and asks for:

  1. Salon name — appears in the header bar
  2. Closed days — tap the days your salon is closed each week (e.g. Sat + Mon). If you're open every day, tap none.
  3. Currencies — pick which currencies you accept (NIS, JD, USD). At least one required.
  4. Business hours — opening and closing time

You can re-run the wizard any time from Reports → Re-run Setup Wizard. Changing currencies later does not erase existing prices — old prices in a currency you disable remain visible in past appointments and reports.

Quick start (after setup)

  1. Staff tab — add each employee: Arabic name, specialty, salary (NIS), commission %
  2. Services tab — add each service and its default price + currency
  3. Expenses tab → Categories — the 8 defaults are loaded; edit or add as needed
  4. You're ready to take bookings

Taking a booking (phone call)

  1. Go to Day tab, pick the date
  2. Tap an empty slot on the grid
  3. Pick client (or + New)
  4. Tap a service → pick employee → duration → price → Add
  5. Add more services if needed
  6. Set start time and total minutes
  7. Save

When the client pays (after service)

  1. Tap the appointment on the day grid
  2. Tap 💰 Mark as Paid
  3. Enter amount received in each currency
  4. Save — the block turns green with ✓

Partial payments are OK. Tap again to update or clear.

Recording an expense

  1. Expenses tab → + Add Expense
  2. Date, category, description, amount, currency
  3. Mark Paid if already paid
  4. Save

End of day (do this every day)

  1. Reports → Export day CSV — pick today → downloads a .csv
  2. Open it in Numbers / Excel — or print it
  3. File it, keep it
  4. Reports → Download JSON backup — save to iCloud Drive or email to yourself

The CSV is your readable daily record. The JSON is the safety net if the phone ever dies.

Monthly report

Monthly tab shows: revenue (total / paid / outstanding), per-employee revenue and commission, payroll (base + commission), expenses, and net per currency. Use ◀ ▶ to change months.

  • Export month CSV — full report as a spreadsheet
  • Print month — a clean printout

Salon open/closed days

  • Your default closed days are set in the wizard.
  • In Calendar: greyed days = closed
  • Tap the selected day once to toggle open/closed
  • Tap a different day to select it, then tap again to toggle
  • Blue dot = day has appointments
  • Reset to my defaults clears all manual overrides

Employee absence

  • Planned vacation: Staff → Vacation → set a date range
  • Emergency today: Day tab → tap the ON button in the employee's column header → OFF
  • Absent employees appear greyed and cannot be booked

⚠ Critical safety rules

  1. Never clear Edge's browsing data or cache — it erases ALL salon data
  2. Never delete this HTML file from Files — that's the app
  3. Back up the JSON at least once a week — the only way to restore if the phone breaks
  4. To move to a new phone: install the app there, then Restore from JSON

Restoring from a backup

  1. Open the app on the new or repaired phone
  2. Reports → ⬆ Restore from JSON
  3. Pick your latest backup file
  4. Confirm — the app reloads with your data

Currency notes

  • You choose which currencies to enable in the wizard (NIS, JD, USD)
  • Prices can be in any enabled currency — mixed within one appointment is allowed
  • The app never converts between currencies — totals are shown per currency
  • Commission is a % of paid amounts, per currency
  • Salaries are entered in NIS only
  • Disabling a currency later does not delete old prices

If something looks wrong

  • Red banner at top → screenshot it and send it for a fix
  • If the page ever looks blank → close and reopen the app
  • If a number is wrong → check the appointment's payment record; the app never guesses
