🧙 Setup wizard (first run)

The first time you open the app, a wizard runs and asks for:

  1. Salon name — appears in the header bar
  2. Closed days — tap the days your salon is closed each week (e.g. Sat + Mon). If you're open every day, tap none.
  3. Currencies — pick which currencies you accept (NIS, JD, USD). At least one required.
  4. Business hours — opening and closing time

You can re-run the wizard any time from Reports → Re-run Setup Wizard. Changing currencies later does not erase existing prices — old prices in a currency you disable remain visible in past appointments and reports.

Quick start (after setup)

  1. Staff tab — add each employee: Arabic name, specialty, salary (NIS), commission %
  2. Services tab — add each service and its default price + currency
  3. Expenses tab → Categories — the 8 defaults are loaded; edit or add as needed
  4. You're ready to take bookings

Taking a booking (phone call)

  1. Go to Day tab, pick the date
  2. Tap an empty slot on the grid
  3. Pick client (or + New)
  4. Tap a service → pick employee → duration → price → Add
  5. Add more services if needed
  6. Set start time and total minutes
  7. Save

When the client pays (after service)

  1. Tap the appointment on the day grid
  2. Tap 💰 Mark as Paid
  3. Enter the amount in each currency, then choose Cash or Card for each
  4. Save — the block turns green with ✓

Partial payments are OK. Tap again to update or clear.

Moving an appointment

  1. Tap the appointment → 🕐 Move
  2. A banner appears at the bottom: "Moving [client] — tap an empty slot"
  3. The appointment block gets an orange outline
  4. Tap a new slot in the same employee's column → moves instantly
  5. Tap a slot in a different employee's column → prompt: "Reassign all services to [name]?"
  6. If the target slot has a conflict → refused with a clear message
  7. To cancel → tap Cancel on the banner

You can also move to a different day: tap Cancel, change the date, then tap 🕐 Move again.

Recording an expense

  1. Expenses tab → + Add Expense
  2. Date, category, description, amount, currency
  3. Mark Paid if already paid
  4. Save

📅 Daily rhythm — do this every day

Before you close the salon, do these three things:

  1. 🖨 Print the day sheet
    Reports → Print day sheet → date = today → Print.
    Shows: every appointment, client, service, payment (cash / card), day totals, and an Unpaid by client list at the bottom showing who still owes you money.
  2. 📄 Export the day CSV
    Reports → Export day CSV → date = today → Export day CSV.
    Downloads salon_day_YYYY-MM-DD.csv to your iPhone's Files app. Same content as the printout, plus a full UNPAID BY CLIENT breakdown with service lines.
  3. 💾 Download the JSON backup — the most important step
    Reports → ⬇ Download JSON backup.
    Downloads salon_backup_YYYY-MM-DD.json. This is the only file that can fully restore your data if the phone dies.

Where to store these files (do at least two):

  • iCloud Drive — in Files, long-press each file → Move → iCloud Drive folder (create one called Salon Backups)
  • Email to yourself — long-press the file → Share → Mail
  • AirDrop to a Mac or iPad
  • Google Drive / Dropbox — Files → Share → pick the app

📆 Weekly rhythm — once a week

  1. Open the app → Reports → ⬇ Download JSON backup
  2. Email it to yourself as a second safety copy
  3. On the phone, delete older JSONs once they're saved in iCloud/email (keep only the latest 2–3 on the phone)
  4. Move the week's daily CSVs into a dated folder in iCloud Drive (e.g. Salon 2026-09 Week 3)

🗓️ Monthly rhythm — end of month

  1. Monthly tab → make sure the right month shows (◀ ▶) → 🖨 Print month.
    Shows: total revenue, per-employee revenue + commission, payroll (base + commission on billed), expenses, unpaid by client, and net per currency.
  2. 📄 Export month CSV.
    Downloads salon_month_YYYY-MM.csv — a full monthly spreadsheet with every section, including the UNPAID BY CLIENT detail.
  3. Save both files to iCloud Drive / email, same as daily
  4. Download one final JSON backup for the month → email to yourself
  5. File the printed monthly report in a physical folder (business records / tax)

📦 What to keep and for how long

File Why Keep?
JSON backup Only way to fully restore if the phone dies Forever (highest priority)
Monthly CSV Business records, taxes, review Forever
Monthly printout Physical record Forever
Daily CSV Daily detail At least 1 year, then optional
Daily printout Paper trail for the day At least 1 year, then optional

If you only save one thing: the JSON backup. Nothing else can restore your data.

✅ Checks and balances

Every day, match what the app says against what's in the drawer and terminal:

  • Cash in the drawer should match the cash amount on the day sheet.
  • Card terminal report should match the card amount on the day sheet.
  • Sum of cash + card should match the paid total for the day.

Monthly:

  • Monthly report revenue should equal the sum of every day's totals for that month.
  • Monthly revenue − payroll − expenses = the net per currency shown at the bottom.
  • Employee commissions are computed on billed amounts — the full service price, whether or not the client has paid yet. You (the owner) are responsible for collecting unpaid balances; the app keeps a list under Unpaid by Client.

If numbers don't match, check the appointment's payment record (tap it on the day grid). The app never guesses — whatever you recorded is what it shows.

💾 Backup & restore in full

The JSON backup is a complete copy of everything: employees, services, clients, appointments, payments, expenses, settings, closed days, and currencies. Restoring it replaces the entire database on the phone.

To back up:

  1. Reports → ⬇ Download JSON backup
  2. Save the file to iCloud Drive or email it to yourself

To restore on a new phone (or after a reset):

  1. Copy the app file to the new phone — email it to yourself, AirDrop from a computer, or download from iCloud Drive
  2. Open the file in Safari → Add to Home Screen
  3. Open the app → the wizard runs → complete it (it just needs a name, days, currencies, hours to get started)
  4. Reports → ⬆ Restore from JSON → pick your latest backup file
  5. Confirm → the app reloads with all your real data back (the wizard setup is overwritten by the backup)

Important: restoring replaces everything. Do not restore an old backup over newer data unless you actually want to go back to that older state.

Monthly report

Monthly tab shows:

  • Revenue — total, paid, outstanding per currency
  • By Employee — billed, paid, unpaid, and commission (on billed) per employee
  • Payroll — base salary + commission per employee
  • Unpaid by Client — who still owes you money this month
  • Expenses — per currency, with paid / unpaid split
  • Net — revenue − payroll − expenses, per currency

Use ◀ ▶ to change months. Export or print from the buttons at the top.

Salon open/closed days

  • Your default closed days are set in the wizard.
  • In Calendar: greyed days = closed
  • Tap the selected day once to toggle open/closed
  • Tap a different day to select it, then tap again to toggle
  • Blue dot = day has appointments
  • Reset to my defaults clears all manual overrides

Employee absence

  • Planned vacation: Staff → Vacation → set a date range
  • Emergency today: Day tab → tap the ON button in the employee's column header → OFF
  • Absent employees appear greyed and cannot be booked

Currency notes

  • You choose which currencies to enable in the wizard (NIS, JD, USD)
  • Prices can be in any enabled currency — mixed within one appointment is allowed
  • The app never converts between currencies — totals are shown per currency
  • Commission is a % of billed amounts, per currency. It does not depend on whether the client has paid.
  • Salaries are entered in NIS only
  • Disabling a currency later does not delete old prices

⚠ Critical safety rules

  1. Never clear Safari's browsing data or cache — it erases ALL salon data from the phone (Settings → Safari → Clear History and Website Data). Avoid this entirely.
  2. Never delete the HTML file from Files — that's the app itself.
  3. Back up the JSON at least once a week (daily is better) — the only way to restore if the phone breaks.
  4. Never restore an old JSON over newer data unless you intend to lose the newer data.
  5. To move to a new phone: install the app there, then Restore from JSON.
  6. Use one browser only. Safari and Chrome each have their own separate data. Stick to one.

If something looks wrong

  • Red banner at top → screenshot it and send it for a fix. It tells us the exact line.
  • Page looks blank → close and reopen the app
  • A number looks wrong → check the appointment's payment record; the app never guesses
  • Data missing after Erase → that's expected; Erase clears everything. Restore from your latest JSON to bring it back.
  • Data missing after switching browsers → each browser has its own data. Stick to one browser.
